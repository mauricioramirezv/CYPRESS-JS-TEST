# Cypress JS Tests

Este proyecto contiene ejemplos básicos de pruebas automatizadas con Cypress en JavaScript.

## 📦 Instalación

```bash
npm install
npx cypress install
```

## 🚀 Comandos

- Ejecutar Cypress en modo visual:

```bash
npm run cypress:open
```

- Ejecutar todas las pruebas en terminal (headless):

```bash
npm run cypress:run
```

## 📂 Estructura

- `home_page.cy.js`: Verifica carga de página inicial.
- `form_interaction.cy.js`: Interacción con un formulario.
- `search_engine.cy.js`: Búsqueda en Bing.
- `dropdown_selection.cy.js`: Selección en dropdown.

## 🧪 Requisitos

- Node.js
- npm
